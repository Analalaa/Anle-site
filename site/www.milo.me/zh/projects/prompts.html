Codex 插件

Prompts

让好问题，不止用一次。

安装插件 ↓

有些问题问得很好，有些回答值得再读。Prompts 是我给自己做的 Codex 对话检索工具，让已经发生过的思考，可以在需要的时候再次派上用场。

  • 找回一句话

    按关键词搜索自己写过的 Prompt 或模型回答，也可以在不同项目之间查找。

  • 把上下文一起带回来

    展开匹配的消息，阅读前后对话，再回到原来的任务。

  • 留在自己的电脑上

    索引本机保存的对话，不依赖嵌入模型或额外的 API Key。

提供 macOS 本地安装包，需要 Codex 和 Python 3.9 或以上版本。安装后检索的是使用者自己电脑里的对话。

安装 Prompts

macOS · Codex 桌面应用与 CLI · Python 3.9+ · 测试版

下载插件包 ↓
  1. 下载插件包并解压，把 prompts 文件夹放在准备长期保留的位置。
  2. 在 prompts 文件夹的上一级打开终端，运行下面的命令。
    codex plugin marketplace add ./prompts
  3. 在 Codex 的插件目录选择「Anle · Prompts」来源并安装 Prompts。如果暂时没有显示，重启 Codex 后再查看。
  4. 新建一个对话，说「打开对话检索面板」。

安装包仅包含程序代码，不含我的对话、索引或缓存。检索在使用者自己的电脑上进行。
