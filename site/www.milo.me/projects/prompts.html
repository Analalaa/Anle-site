Codex plugin

Prompts

A good question deserves a second life.

Install plugin ↓

Some questions are worth asking again. Some answers are worth keeping. I made Prompts to search my own Codex conversations and return to ideas when I need them.

  • Find a thought

    Search prompts and replies by keyword, within a project or across projects.

  • Keep the context

    Read the surrounding conversation, then open the original task.

  • Keep it local

    Search conversations saved on your computer, without an embedding model or an extra API key.

A local installation package for macOS, requiring Codex and Python 3.9 or newer. It searches conversations stored on the installing user’s own computer.

Install Prompts

macOS · Codex desktop & CLI · Python 3.9+ · Beta

Download plugin ↓
  1. Download and extract the package. Keep the prompts folder in a permanent location.
  2. Open a terminal in the parent directory of the prompts folder and run the command below.
    codex plugin marketplace add ./prompts
  3. In the Codex Plugins directory, select the Anle · Prompts source and install Prompts. Restart Codex if it does not appear yet.
  4. Start a new chat and ask: “Open the conversation search panel.”

The package contains application code only, with none of my conversations, indexes, or caches. Searches run on the user’s own computer.
