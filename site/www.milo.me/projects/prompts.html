Prompts

A good question deserves a second life.

Some questions are worth asking again. Some answers are worth keeping. I made Prompts to search my own Codex conversations and return to ideas when I need them.

  • Find a thought

    Search prompts and replies by keyword, within a project or across projects.

  • Keep the context

    Read the surrounding conversation, then open the original task.

  • Keep it local

    Search conversations saved on your computer, without an embedding model or an extra API key.

A personal local plugin. A public installation link is being prepared.
